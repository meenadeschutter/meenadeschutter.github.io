# meenadeschutter.github.io

Personal site of Meena De Schutter, puzzle nerd and maker of things: apps, lenses, games, sewing, puzzles and doodles. A new version is being pieced together.

- Site: https://meenadeschutter.github.io
- LinkedIn: https://linkedin.com/in/meena-de-schutter-194297127

## Work in progress (`wip` branch)

This branch holds the redesign in progress. The live site (on `master`) is unchanged.

- `docs/plan.md`: what's done and what's next
- `docs/brand.md`: copy, colors, type and design rules
- `content/`: data for each piece (lenses, puzzles)
- `design/`: design mock-ups of the homepage and the lenses page
